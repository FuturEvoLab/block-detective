    MODULE 04 // SMART MONEY

    聪明钱分析

    批量导入钱包

    从排行榜复制一整段内容粘贴进来，自动提取地址批量评分

    可以直接粘贴 DexScreener「Top Traders」、GMGN、Nansen、Arkham、Dune 等页面或表格里复制的内容，文字、链接混在一起也没关系；会自动提取所有 0x 地址（一次最多 60 个，已标记的交易所 / 合约会跳过），按上方选择的链分析。B 级以上、非机器人的钱包自动进入排行榜，机器人会跟踪记录它们的研究数据。

    MODULE 05 // SYSTEM CONFIG

    设置

    API Key 只保存在本机的 data/config.json 里。

    语言

    Language · 言語

    配色

    HUD 主色。绿色配色下“流入”改用青绿色，避免和主色混淆。

    服务

    改了代码之后点一下，服务会重新启动并加载最新代码，页面自动刷新。打开界面：Mac 双击 启动区块侦探.command，Windows 双击 启动区块侦探.bat。

    数据备份

    每天自动把标签库、监控列表、设置、排行榜、模拟账本和研究数据库备份到 Mac 内置硬盘，保留最近 14 天。外接硬盘出问题时可以从这里找回。

    下载备份 zip
    zip 里是 data/ 的全部数据（不含缓存和 API Key）。换电脑时在新机器上点"从 zip 恢复"导入：会先自动备份当前数据，恢复后服务自动重启。
